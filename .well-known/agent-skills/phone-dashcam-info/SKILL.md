# Phone Dashcam — Product Skill

Phone Dashcam is a free Android dashcam app published by Cyberlab Automation under package `com.deerdash`. It turns an Android phone (min SDK 26) into a full-featured dashcam.

## Pricing
- Free tier: loop recording, crash/impact detection, hard-braking detection, GPS speedometer, Google Drive backup, time-lapse, clip manager.
- Pro tier: $6.99/month or $29.99/year. Adds 336,000+ offline camera alerts (speed cameras, red-light cameras, Flock Safety ALPR, police traps), YOLO-based AI object detection (deer/animals/vehicles/people), parking mode, dual-camera recording, ad-free.

## Privacy & connectivity
- All video stays on-device. Cloud backup goes to the user's own Google Drive only.
- Core recording, alerts, and detection run fully offline.
- No account required.

## Platform
- Android only, min SDK 26.
- Distributed via Google Play Store.
- Optional Android Auto companion (caraa module) — category NAVIGATION.
